## Design Context

### Users
NetApp ONTAP storage engineers and operators who need to inspect AutoSupport bundles during configuration review, support handoff, and incident triage.

### Brand Personality
Dense, exact, and calm. The interface should feel like an operations workbench: trustworthy, scannable, and built for repeated use.

### Aesthetic Direction
Industrial utilitarian light UI with compact tables, restrained color, clear status chips, and high information density. Avoid marketing-style hero layouts and decorative dashboards.

### Design Principles
- Put source facts first, with missing data explicitly marked.
- Make the first viewport useful for triage: cluster, node, protocol, capacity, and risk signals.
- Keep tables compact but readable for Excel/PPT migration later.
- Separate active configuration from unavailable or unused configuration.
- Preserve raw command output where interpretation would hide important detail.
